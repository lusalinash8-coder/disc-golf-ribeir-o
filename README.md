# Disc Golf Ribeirão

Quiero que me ayudes a hacer una pagina web para un grupo, deportivo e inclusivo enfocado en promover, enseñar y practicar el disc golf (golfe de disco) en Ribeirão Preto y sus alrededores. Dirigido por Oky Leon y asociado a diferentes entidades como: USP, AJED, Disc Golf Brasil, PDGA, se encargan de promover el deporte mediante entrenamientos, videos en redes sociales y campeonatos. 

"A Turma do Disc Golf" aunque siempre en torneos y demas actividades se junta con estas entidades es diferente y no tiene vinculos legales con ellas (por si acaso). 

La idea es crear una pagina web promoviendo el grupo para que cada vez mas y mas gente se una, ademas tambien la idea es tener un apartado de torneos, donde se pueda compartir a personas el link del torneo, puedan ver toda la informacion y ademas separar y comprar su cupo a traves de la pagina. 

Ya tenemos el branding (te lo adjunto en el pdf). Quiero que sea una pagina web innovadora, chevere, moderna, deportiva.

## Abrir la página

Para ver el sitio funcionando en tu máquina, doble clic en **`abrir-site.command`** (en la raíz del proyecto). Se abre una ventana de terminal, arranca el sitio y lo abre solo en el navegador.

No cierres esa ventana mientras navegas — al cerrarla, el sitio deja de funcionar.

Si prefieres hacerlo a mano por terminal:

```sh
npm run dev
```

y luego abre **http://localhost:8080** en el navegador.
